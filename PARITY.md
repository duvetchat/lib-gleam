# Parity with duvet-client

Where `libduvet` stands against the Dart package in `../duvet-client`, which is
the source of truth for behaviour. `tool/parity.sh` extracts every public Dart
type, endpoint and client method and checks that each one has a line here; run
it with `--strict` to fail while anything is still unported, or with `--write`
to add lines for new Dart symbols (ticked lines are kept).

A line is `- [ ] \`DartName\`` while the symbol is unported and
`- [x] \`DartName\`` once its Gleam counterpart is in place; the note that
follows names the counterpart, or the reason for a deliberate difference.
